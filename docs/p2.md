## 三、阶段 A：商品资产人工验收准备

### A1. 商品分组核对

重点检查：

- 76 个商品分组。
- 24 组跨图库相似候选。
- 97 对疑似重复图片。
- 76 张商品主图。
- 395 张质量问题图片。

尤其核对 24 组跨图库候选，禁止自动合并不确定的商品。

### A2. 主图质量审计

检查 76 张已选主图是否命中质量问题。

生成：

- 主图质量汇总。
- 主图问题清单。
- 可替换主图候选。
- 仅有一张可用图片的商品清单。

不要仅根据自动评分决定最终主图。

### A3. 商品人工审核工作表

生成一个完整的 Excel 工作簿：

```
catalog/review/customer_confirmation.xlsx
```

至少包含以下工作表：

1. 商品总览：76 件商品，每件有编号、缩略图、临时名称、分类、主图、图片数量。
2. 商品信息确认：正式名称、款号、分类、颜色、材质、尺码、售价、库存。
3. 图片确认：正面、背面、细节、面料、模特图。
4. 跨图库候选：24 组相似商品及其对比图片。
5. 质量问题：需要人工判断的图片。
6. AI 准备度：76 件商品的 AI 素材情况。

图片应尽可能直接嵌入工作簿或通过清晰的相对路径关联。

所有客户需要填写的字段留空，不得编造商品经营数据。

### A4. 审核状态管理

建立独立的人工审核记录：

- 未审核。
- 已审核。
- 需要补充资料。
- 商品分组待确认。
- 图片需要更换。
- 已确认可上架。

支持导出和恢复审核结果。

不能只把修改保存在浏览器内存中。

### A5. 客户资料需求文档

生成：

```
docs/customer-information-request.md
```

清晰列出需要客户提供的：

- 品牌 LOGO 和品牌资料。
- 商品正式名称和款号。
- 商品价格和材质。
- 商品尺码和颜色。
- 商品库存。
- 尺码表和详情文案。

- AI 图片制作及第三方服务使用授权。

完成阶段 A 后，不要等待客户回复才开始阶段 B。

## 四、阶段 B：品牌视觉系统设计

品牌暂定名称：鄂多蘭。

正式名称及 LOGO 以客户最终确认为准。

### B1. 品牌定位

推荐设计方向：

现代东方服饰美学 + 天然织物质感 + 极简高级感。

品牌气质：

- 温暖。
- 优雅。
- 自然。
- 克制。
- 高级。
- 有一定地域文化辨识度。

不要做成传统批发商城，也不要做成普通淘宝店铺的复制品。

### B2. 色彩系统

建立统一设计令牌：

- 羊绒白：#F5F1E9
- 燕麦色：#D9C8AE
- 暖褐色：#A18B75
- 深咖色：#55463D
- 墨黑色：#292724

允许根据实际设计调整，但保持整体协调。

### B3. 视觉原则

- 大面积留白。
- 高质量商品摄影。
- 时装杂志式排版。
- 商品图片优先。
- 精致的字体层级。
- 细腻的交互反馈。
- 统一的按钮、图标、间距和圆角。
- 移动端优先。

不要使用大量渐变、玻璃拟态、夸张动画或无意义装饰。

不要直接复制参考商城的页面。
